# Employment Value Gate — Curriculum Authoring Standard (canonical)

> **Status: Canonical.** Part of the Aladiah platform canon (`/docs/standards`). Required reading for
> anyone authoring curriculum — Claude Code, AI agents, and human authors. Applies to **every program**:
> Scrum Master, Business Analyst, Project Manager, Data Analyst, and all future programs (Cybersecurity,
> DevOps, AI Engineering, …). Aligns with NORTH_STAR: Aladiah sells **career transformation, not course
> completion** — so every unit of curriculum must produce employer-visible evidence, not just knowledge.

## The Gate

**No lesson is "ready" until all five answers are YES:**

1. **What capability does the student gain?** (a concrete, nameable skill — not "awareness of X")
2. **What artifact is produced?** (every lesson ends with a tangible deliverable)
3. **Would a hiring manager care?** (the artifact maps to something employers actually evaluate)
4. **Can the artifact be shown publicly?** (LinkedIn / GitHub / portfolio-ready — not a private worksheet)
5. **Does it improve interview performance?** (the student can discuss or demonstrate it in an interview)

If any answer is **NO**, the lesson is not done — upgrade the artifact or reframe the lesson until it
passes. (Example upgrades from BA Module 2: "Competency Self-Assessment" → "AI Business Analyst Career
Readiness Assessment"; "Communication Charter" → "Stakeholder Communication Plan + worked four-audience
sample".)

## How to apply it

- **Run the gate WHILE authoring, not after.** Each lesson is written with its artifact and the five
  answers in mind from the first draft.
- **Record it.** Every authored module ends with an **Employment-value review** table:
  `Lesson | capability gained | artifact | hiring manager cares? | publicly showcaseable? | improves interview?`
- **Module-level rollup.** A module's set of artifacts should assemble toward that program's portfolio
  artifacts and career outcomes (see each program's `00_AUTHORING_BLUEPRINT.md` + the Career Outcome
  Matrix in `COMPETENCY_TAXONOMY.md`).

## Why it exists

Most platforms produce *notes*; employers hire *evidence*. The gate is what keeps every Aladiah lesson
oriented to the salary ladder and the destination role, and what prevents a program from drifting back
into a generic certification course. It is the difference between "good" and "employment-grade."
