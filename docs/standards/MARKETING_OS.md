# MARKETING_OS.md — Aladiah Marketing Operating System

> **Canon document. Every human and AI agent doing marketing work is bound by this.**
> Last updated: 2026-06-21

---

## North Star

Every marketing employee and AI agent exists to move people through one pipeline:

```
Attention → Trust → Community → Transformation → Employment
```

Primary metric: **lives transformed.**

Secondary metrics (views, likes, followers, virality) are diagnostic only.
They are never reported as wins.

A marketing asset that does not advance someone toward career transformation
is the wrong asset. Do not publish it.

---

## The Universal Asset Pipeline

No asset — from any human or AI — ships without passing every stage:

```
Idea
  → Research
    → Draft
      → Design
        → QA
          → Approval
            → Schedule
              → Publish
                → Measure
                  → Learn
                    → Reuse
```

### Stage Definitions

| Stage | What it means | Owner |
|---|---|---|
| **Idea** | A problem worth solving or a story worth telling, tied to a flywheel stage | Anyone |
| **Research** | Audience defined, platform defined, objective defined, CTA defined | Content Studio Director |
| **Draft** | First version created, fact-checked, source-referenced | Assigned writer/agent |
| **Design** | Visual produced per brand standard, mobile-tested | Design Director |
| **QA** | Full QA checklist completed by a person who did not create the asset | Marketing QA Director |
| **Approval** | CMO or delegated director signs off | CMO |
| **Schedule** | Published date set, platform confirmed, tracking tags applied | Growth Director |
| **Publish** | Asset live with URL confirmed | Platform owner |
| **Measure** | KPIs pulled at 24h, 7d, 30d | Growth Director |
| **Learn** | What worked, what did not, why | Content Studio Director |
| **Reuse** | High-performing assets recycled into new formats or markets | Content Studio Director |

**No one approves their own work. Ever.**

## Roles

### Chief Marketing Officer (CMO)

**Mission:** Own the entire growth engine.

**Authority over:** Brand, Content, Community, Admissions, Growth, Partnerships, Analytics.

**Definition of Ready** — a marketing initiative is ready to start when:
- [ ] Target audience defined
- [ ] Platform defined
- [ ] Objective defined
- [ ] CTA defined
- [ ] Owner assigned
- [ ] Success metric assigned

**Definition of Done** — an initiative is done when:
- [ ] Asset created
- [ ] QA approved
- [ ] Published
- [ ] Tracked
- [ ] Performance measured at 24h, 7d, 30d

**Daily review minimum:**
- Content pipeline status
- Publishing calendar (next 7 days)
- Performance dashboard
- Admissions funnel
- Growth metrics vs. weekly target

**KPIs:**

| KPI | Frequency |
|---|---|
| Waitlist growth | Daily |
| Applications submitted | Daily |
| Enrollments | Weekly |
| Cost per lead | Weekly |
| Conversion rate (lead → student) | Weekly |
| Community growth | Weekly |
| Revenue attribution by channel | Monthly |

### Content Studio Director

**Mission:** Create content that teaches. Not entertainment. Not trends.

**Approved output formats:**
- LinkedIn posts
- Long-form articles
- Email sequences
- Video scripts
- Threads
- Case studies

**Daily deliverables:**

| Output | Count |
|---|---|
| LinkedIn posts | 10 |
| Long-form articles | 5 |
| Email drafts | 5 |
| Video scripts | 30 |

**Definition of Ready:**
- [ ] Topic approved by CMO or flywheel stage assignment
- [ ] Target audience defined
- [ ] Desired outcome defined
- [ ] Research complete (sources cited)

**Definition of Done:**
- [ ] Grammar checked
- [ ] Brand language aligned
- [ ] Facts verified (no false salary claims, no misleading statistics)
- [ ] CTA included and mapped to flywheel stage
- [ ] Stored in content repository with file name, date, topic tag

**Evidence required for every completed asset:**
- Published URL
- Source file path
- Revision history (who changed what)
- QA approval signature

### Video Content Director

**Mission:** Turn ideas into emotional stories that move people to act.

**Approved output formats:**
- TikTok
- Instagram Reels
- YouTube Shorts
- Founder videos
- Documentaries

**Daily deliverables:**

| Status | Count |
|---|---|
| Published | 3 |
| Edited (ready to schedule) | 10 |
| In production pipeline | 20 |

**Definition of Done:**
- [ ] Hook validated (first 3 seconds tested — see QA checklist)
- [ ] Captions added
- [ ] Branding visible (logo, colors, tone)
- [ ] CTA present and spoken or displayed
- [ ] Exported at platform-correct spec
- [ ] Scheduled with tracking link

**QA checklist — every video:**
- [ ] Do the first 3 seconds create a reason to keep watching?
- [ ] Are subtitles present and accurate?
- [ ] Is Aladiah branding visible within first 5 seconds?
- [ ] Does the video deliver a concrete insight or story beat?
- [ ] Is the CTA specific (not "follow us" — a next step toward transformation)?

### Storytelling Director

**Mission:** Own the narrative. This is not a content role. It is the soul of the brand.

**Permanent story series:**

| Series | Subject |
|---|---|
| The Man Who Refused | Founder story — refusing mediocrity |
| Future of Work | The AI era and what it demands |
| Before Aladiah | Career pain and professional stagnation |
| After Aladiah | Career transformation and new identity |

**Approved output formats:**
- Founder story (written + video)
- Student transformation stories
- Africa and Dominican Republic stories
- Career before/after narratives

**Definition of Done — every story must contain:**
- [ ] Conflict (the problem before)
- [ ] Struggle (what it cost)
- [ ] Lesson (what was learned)
- [ ] Transformation (what changed)
- [ ] Hope (what is now possible)

A story without all five elements is not a story. It is a testimonial. Return it.

### Growth Director

**Mission:** Own the numbers. No excuses. No rounding. No storytelling about numbers.

**Daily dashboard — must be able to answer:**

| Question | Frequency |
|---|---|
| What increased today? | Daily |
| What decreased today? | Daily |
| Why? | Daily |
| What action is being taken? | Daily |

**Tracked metrics:**

```
Followers (by platform)
Reach (organic + paid)
Leads generated
Waitlist size
Applications submitted
Enrollments confirmed
Revenue (attributed by channel)
```

**Daily report format:**
```
DATE: YYYY-MM-DD

INCREASED:
  [metric] — [value] — [reason]

DECREASED:
  [metric] — [value] — [reason]

ACTIONS TAKEN:
  [action] — [owner] — [deadline]
```

Submitting a report that says "I was working on growth" is not a report. Reject it.

### Marketing QA Director

**Mission:** Protect the brand. Nothing ships without QA. Nobody approves their own work.

**Every asset must pass three gates:**

**Gate 1 — Accuracy**
- [ ] No false salary claims
- [ ] No fabricated statistics
- [ ] No misleading before/after framing
- [ ] All numbers sourced

**Gate 2 — Brand**
- [ ] Correct logo version (approved canonical asset)
- [ ] Correct color palette
- [ ] Correct voice (authoritative, not casual; professional, not corporate)
- [ ] Correct language (aligned with NORTH_STAR.md mission)

**Gate 3 — Quality**
- [ ] No typos
- [ ] No grammar issues
- [ ] No broken links
- [ ] No placeholder text
- [ ] CTA present and functional

**Mission gate — final question before approval:**

> Does this asset help someone transform their career?

If **yes**: approve.
If **no**: reject. Return with written reason. Do not publish.

## Marketing Readiness Score

Used to assess launch readiness. Measured monthly.

| Dimension | Weight |
|---|---|
| Content Library (volume + quality + variety) | 25% |
| Publishing Engine (calendar, scheduling, consistency) | 20% |
| Brand Compliance (logo, color, voice, QA pass rate) | 15% |
| Community Operations (response time, growth, sentiment) | 15% |
| Analytics (dashboard coverage, attribution, reporting cadence) | 15% |
| QA Compliance (% of assets QA-reviewed before publish) | 10% |

**Launch thresholds:**

| Score | Meaning |
|---|---|
| 90% | MVP launch authorized |
| 95% | Flagship launch authorized |
| 98% | World-class launch — full market entry |

## Proof Standard

No one in marketing says "I was working on marketing."

Every person and every AI agent must be able to answer:

| Question | Required answer |
|---|---|
| What was produced? | Named asset with file/URL |
| Why was it produced? | Flywheel stage it serves |
| What objective does it serve? | Named KPI |
| Where is it stored? | Repository path or published URL |
| What KPI does it impact? | Metric name + current value |

If any answer is missing, the work is not done.
