## 2. Question bank (10 new)

**Q1 · Discovery workshops · Foundational** — correct: index 1
The facilitator's primary job in a discovery workshop is to:
1. Dominate with their own ideas
2. Create structure and safety so the group surfaces and converges on insights
3. Take notes silently
4. Decide the outcome alone
**a: 1** — *Facilitation provides structure and psychological safety so the group produces and converges on insight — guiding process, not owning content.*

**Q2 · Event storming · Practitioner** — correct: index 3
Event Storming is most useful for:
1. Estimating budgets
2. Designing the UI
3. Writing the BRD alone
4. Collaboratively mapping a business process/domain as a series of events with stakeholders
**a: 3** — *Event Storming gathers stakeholders to map domain events/flows on a wall — fast shared understanding of complex processes and boundaries.*

**Q3 · Story mapping · Foundational** — correct: index 0
A user story map is organized to:
1. Show the user journey across the top with prioritized slices beneath, revealing scope and releases
2. Rank developers
3. List bugs
4. Replace the backlog index
**a: 0** — *Story mapping arranges activities along the journey with prioritized detail beneath — exposing scope, gaps, and coherent release slices.*

**Q4 · Impact mapping · Practitioner** — correct: index 2
Impact mapping connects:
1. Servers to databases
2. Tasks to dates
3. Goal → actors → impacts → deliverables, keeping work tied to outcomes
4. People to salaries
**a: 2** — *Impact mapping links goal → actors → impacts (behavior changes) → deliverables, anchoring scope to outcomes and exposing assumptions.*

**Q5 · Prioritization workshops · Foundational** — correct: index 1
In a prioritization workshop, the facilitator's key contribution is:
1. Choosing the priorities themselves
2. Providing shared, transparent criteria/method so the group decides defensibly
3. Letting the loudest voice win
4. Avoiding a decision
**a: 1** — *The facilitator supplies a shared method/criteria (value/effort, WSJF) so the group decides transparently — not deciding for them.*

**Q6 · Conflict workshops · Senior** — correct: index 3
Facilitating two groups in open conflict, the strongest first move is:
1. Force an immediate vote
2. Take the more senior side
3. Cancel the session
4. Establish shared goals and ground rules, then surface interests behind positions before seeking options
**a: 3** — *Move from positions to interests under shared goals, then generate options — interest-based facilitation resolves conflict more durably than forcing votes.*

**Q7 · Executive decision forums · Senior** — correct: index 0
Facilitating an executive decision forum, the BA should:
1. Frame the decision, options, trade-offs, and a recommendation, and drive to a clear decision and owner
2. Present every detail
3. Let it run open-ended
4. Avoid making a recommendation
**a: 0** — *Executives need a framed decision (options/trade-offs/recommendation) facilitated to a clear decision and owner, respecting their time.*

**Q8 · Retrospectives · Foundational** — correct: index 2
A retrospective's purpose is to:
1. Assign blame
2. Report status to managers
3. Inspect how the team works and agree concrete improvements in a safe setting
4. Re-plan the backlog
**a: 2** — *A retrospective is a blameless inspect-and-adapt on the team's process, producing a few concrete, owned improvements.*

**Q9 · Multi-team facilitation · Practitioner** — correct: index 1
Facilitating alignment across 6 teams, the biggest added challenge vs one team is:
1. Nothing changes
2. Managing dependencies, shared decisions, and consistent understanding across groups with divergent context
3. Fewer people to manage
4. Less preparation
**a: 1** — *Multi-team facilitation must handle cross-team dependencies, shared decisions, and aligning divergent contexts — more structure and prep than single-team.*

**Q10 · Convergence technique · Practitioner** — correct: index 3
Mid-workshop, discussion circles with no convergence. The facilitator should:
1. Let it continue indefinitely
2. End the workshop
3. Decide unilaterally
4. Use a convergence technique (dot-voting, timeboxing, an agreed decision rule) to reach a decision
**a: 3** — *When stuck in divergence, apply a convergence technique to move the group to a decision — a core facilitation skill.*
