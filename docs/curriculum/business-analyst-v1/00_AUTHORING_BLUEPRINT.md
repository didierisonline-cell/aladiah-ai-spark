# AI Business Analyst — Authoring Blueprint (lesson-by-lesson)

> Status: **Curriculum blueprint only — NO lesson content authored here.** Defines every lesson's
> title, objective, competency, produced output, and its simulation/portfolio/lab/assessment/cert
> dependencies, so authoring can proceed against a validated structure (not a template generator).
> Built on the frozen 13-slug competency model, the ~330-question bank, the 10-sim suite, and the
> 8-artifact portfolio. Replaces the retired `seed-ai-business-analyst` placeholder (unpublished via
> migration `20260620130000_retire_placeholder_ba_course.sql`).
>
> **Shape:** 15 modules · 6 phases · **75 unique lessons** (5/module) · each lesson produces an output
> that rolls up into one of the 8 portfolio artifacts · each module has a `chapter_end` assessment
> drawn from the tagged question bank. Every lesson is distinct and progressive — no duplication.

## Legend
Competency = primary `ba:` slug. Output = the small deliverable the lesson produces (rolls up to a
Portfolio Artifact, "P#"). Sim = simulation this lesson is a prerequisite for. Lab = hands-on lab.
