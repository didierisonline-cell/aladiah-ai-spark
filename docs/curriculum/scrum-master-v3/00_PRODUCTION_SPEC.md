**Purpose:** the authoritative quality bar + template for making the flagship *real* (not AI scaffolds). Every module is produced to this spec, then human-reviewed and published.

## Definition of "REAL" per asset
| Asset | "Real" means |
|---|---|
| **Lesson** | Authored **transcript** (1,200–1,800 words) → **HeyGen avatar video** + **ElevenLabs audio** + **downloadable resource** (PDF/template) + **assignment** with rubric. No empty rows. |
| **Quiz** | 60 questions/module, 4 options, 1 correct, **rationale per answer**, difficulty (easy/med/hard 30/50/20), **tagged** (below). |
| **Simulation** | Branching scenario: company, stakeholders, conflict, ≥3 decision points, scoring rubric, model answer. **Human-reviewed** (`human_reviewed=true`). |
| **Lab** | Tool (Jira/Miro/Confluence/Azure DevOps), step-by-step task, starter artifact, deliverable, grading rubric. |
| **AI Co-Pilot Challenge** | Real-world prompt + expected AI output + "evaluate the AI" critique rubric. |
| **Interview Prep** | Behavioral + scenario + leadership questions with STAR model answers + evaluation criteria. |
| **Portfolio** | Deliverable spec + employer-value rubric + example. |
| **Executive Sim** | Board/exec-level crisis, stakeholders, budget, board-deck deliverable. |
| **Employer Validation** | Checkpoint criteria an employer panel signs off. |
| **Certification** | Blueprint (domain weights) + **200-question final exam** + passing logic. |
| **Capstone** | The Enterprise Transformation Command Center (see CAPSTONE.md). |
