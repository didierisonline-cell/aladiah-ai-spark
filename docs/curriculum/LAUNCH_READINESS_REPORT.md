## The honest signal (why DB programs score lower than they look)
**Simulations, Labs, Portfolios, Interview Prep, and AI-Mentor prompts are not yet in the DB content model** — they exist as code only for the **flagship** (AI Scrum Master). So a DB program with full lessons + quizzes still caps around ~55% until those dimensions are authored into the platform. **That is the intended “looks finished but isn't” signal** — it prevents launching a program that's 60–70% complete underneath.
