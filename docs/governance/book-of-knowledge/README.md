# The Aladiah Book of Knowledge

**Status: Established by FD-2026-011 — the permanent library of institutional
knowledge.** Registry key: `book-of-knowledge`.

## The organizing law (FD-2026-011)

```
BOOKS contain MANUALS
MANUALS contain STANDARDS
STANDARDS contain PROCEDURES
PROCEDURES generate WORK ORDERS
WORK ORDERS produce EVIDENCE
EVIDENCE updates the COMPANY BRAIN
the COMPANY BRAIN improves future STANDARDS
```

This lifecycle is **the permanent institutional learning loop**: doctrine
flows down into work; evidence flows back up into better doctrine. Nothing
in the Book is exempt from being improved by what the Institution learns.

## Rules

1. Doctrine enters a Book only through its governing lifecycle (constitutional
   lifecycle for Book I; the Permanent Management Rule for Book II; the
   standards lifecycle of M02 §P2 for Book III).
2. A Book never contains ungoverned text: everything shelved is registered,
   genome-carrying, and Brain-mirrored.
3. Books are append-organized: reorganization is a founder decision recorded
   like any other.
