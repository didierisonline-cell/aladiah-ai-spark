## Folder Structure

```
/brand/
  official/       ← Source-of-truth mark and lockup files (SVG + PNG)
  social/         ← Pre-sized exports for each platform (profile, banner)
  video/          ← Intro/outro cards, lower thirds, overlays
  certificates/   ← Seal and lockup variants for certificates
  press-kit/      ← High-res exports for press/partner use
```
